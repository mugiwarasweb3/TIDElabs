# TIDElabs - Where Retro Meets Web3 🚀

A nostalgic Web3 experience that combines retro aesthetics with modern blockchain technology.

## Features

- 🎮 **Retro Design**: Matrix-inspired background with glowing green aesthetics
- 🔗 **Web3 Integration**: Simulated wallet connection functionality
- 📧 **Waitlist Registration**: Email-based early adopter registration
- 💰 **Donation System**: ETH donation functionality
- 🔗 **Referral System**: Social sharing with rewards
- 📱 **Social Sharing**: Share on X (Twitter), Reddit, Telegram, and Lens
- 📱 **Responsive Design**: Works perfectly on all devices

## Tech Stack

- Pure HTML5, CSS3, and JavaScript
- No external dependencies
- Optimized for Vercel deployment
- Mobile-first responsive design

## Deployment

This project is optimized for Vercel deployment:

1. Connect your GitHub repository to Vercel
2. Deploy automatically - no build step required
3. Enjoy your retro Web3 experience!

## Local Development

```bash
# Start local server
python -m http.server 3000

# Or use any static file server
npx serve .
```

## Features Overview

### Wallet Connection
- Simulated Web3 wallet connection
- Toggle connection state
- Shows referral options when connected

### Waitlist Registration
- Email validation
- Real-time counter updates
- Success notifications

### Donation System
- ETH amount input with validation
- Simulated donation processing
- Thank you notifications

### Social Sharing
- X (Twitter) integration
- Reddit sharing
- Telegram sharing
- Lens Protocol support

### Referral System
- Appears after wallet connection
- Multiple platform sharing
- Reward tracking ready

## Design Philosophy

TIDElabs embraces the nostalgic feel of early computing and hacker culture while providing modern Web3 functionality. The Matrix-inspired design creates an immersive retro-futuristic experience.
